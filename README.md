 # Projeto Telecom X — Análise de Evasão de Clientes (Churn)

Neste desafio, atuei como **Assistente de Análise de Dados** na empresa Telecom X, participando do projeto **"Churn de Clientes"**.  
A empresa enfrenta um alto índice de cancelamentos e precisa compreender os principais fatores que levam à perda de clientes.

Meu objetivo foi **coletar, tratar e analisar os dados**, utilizando Python e suas principais bibliotecas, para gerar **insights relevantes** que apoiem futuras etapas de modelagem preditiva e estratégias de retenção.

---

## Objetivo do Projeto

- Entender o perfil dos clientes que cancelam o serviço  
- Identificar padrões relacionados à evasão (churn)  
- Explorar variáveis contratuais, financeiras e comportamentais  
- Gerar insights que apoiem estratégias de retenção  

---

## O que foi realizado

- Importação e manipulação de dados a partir de uma API  
- Aplicação do processo ETL (Extração, Transformação e Carga)  
- Criação de visualizações estratégicas para identificar padrões e tendências  
- Realização de uma Análise Exploratória de Dados (EDA)  
- Elaboração de relatório analítico com insights relevantes  

---

## Processo ETL

### Extração
- Importação dos dados brutos para o ambiente de análise  

### Transformação
- Tratamento de valores ausentes  
- Padronização de variáveis categóricas  
- Conversão de variáveis binárias (Sim/Não → 1/0)  
- Criação de métricas auxiliares para análise  

### Carga
- Conjunto de dados final preparado para análise exploratória e visualização  

---

## Análise Exploratória de Dados (EDA)

Durante a EDA, foram analisadas variáveis categóricas e numéricas relacionadas à evasão de clientes.

### Principais análises realizadas:

- Tempo de Contrato × Evasão  
- Valor Mensal × Evasão  
- Gasto Total × Evasão  
- Tipo de Contrato × Evasão  
- Serviços Adicionais × Evasão  
- Gênero × Evasão  
- Método de Pagamento × Evasão  
- Análise de Correlação entre Variáveis  

Essas análises permitiram identificar padrões claros de comportamento associados ao churn.

---

## Conclusões e Insights

A análise permitiu identificar alguns fatores-chave associados à evasão de clientes:

- Clientes com pouco tempo de contrato são mais propensos ao churn  
- Valores monetários elevados aumentam a chance de cancelamento  
- Contratos mensais apresentam maior taxa de evasão  
- A ausência de serviços adicionais está relacionada a maior rotatividade  
- Clientes mais engajados e com maior gasto acumulado tendem a permanecer na base  
- O gênero não se mostrou um fator determinante isoladamente  
- O método de pagamento apresentou forte relação com a evasão, com maior rotatividade entre clientes que utilizam cheque eletrônico

## Recomendações Finais

Com base nos insights obtidos, recomenda-se:

- Criar estratégias de retenção nos primeiros meses de contrato  
- Oferecer descontos ou planos personalizados para clientes com valores elevados  
- Incentivar a migração para contratos de maior duração  
- Promover pacotes com serviços adicionais  
- Estimular o uso de métodos de pagamento automáticos  
- Utilizar os dados analisados como base para modelos preditivos de churn
